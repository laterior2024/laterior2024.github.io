shorts-maker 개인정보처리방침

최종 수정일: 2026년 11월 25일 · English version below

1. 이 방침이 다루는 것

shorts-maker(이하 '이 프로그램')는 운영자가 자기 컴퓨터에서 쓰는 쇼츠 편집 프로그램이에요. 이 방침은 이 프로그램이 구글 계정(유튜브) 연결로 받는 정보를 어떻게 쓰고 보관하는지 설명해요.

2. 요청하는 구글 권한과 쓰는 곳

  • youtube.upload — 연결한 본인 채널에 완성한 영상을 올리고 썸네일을 정할 때만 써요.
  • youtube.force-ssl — 올린 영상에 고정 댓글을 달고, 연결한 채널의 이름·프로필 그림을 확인하고, 편집에 참고할 원본 영상의 공개 댓글(글·좋아요 수)을 읽을 때 써요.

이 밖의 목적(광고, 판매, 다른 서비스 학습 등)으로는 쓰지 않아요.

3. 받는 정보와 보관 장소

  • 구글이 주는 연결 열쇠(액세스·새로고침 토큰), 연결한 채널의 번호·이름·핸들·프로필 그림.
  • 원본 영상의 공개 댓글 글과 좋아요·답글 수 — 댓글을 쓴 사람의 이름이나 계정은 저장하지 않아요.

모든 정보는 운영자의 컴퓨터 안 프로그램 폴더에만 저장되고, 운영자가 운영하는 다른 서버로 보내지 않아요. 읽은 댓글은 하루 뒤 다시 받아 오고, 작업을 지우면 그 작업의 댓글 정보도 함께 지워져요.

4. 다른 곳에 주는 정보

구글 사용자 정보를 팔거나 다른 사람에게 넘기지 않아요. 다만 영상 편집 글(대본·제목 등)을 만들 때, 원본 영상의 공개 댓글 글(이름 없이)을 AI 글쓰기 서비스(Anthropic Claude API)에 보내 반응을 요약할 수 있어요. 이 정보는 그 요약에만 쓰여요.

5. 구글 API 서비스 사용자 데이터 정책

이 프로그램이 구글 API 에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API Services User Data Policy (제한적 사용 요건 포함)를 따라요.

6. 연결 끊기와 정보 지우기

  • 프로그램의 설정 → 📤 유튜브 직접 올리기 → 🔌 이 채널 끊기를 누르면 그 채널의 열쇠가 지워져요.
  • 구글 계정의 서드 파티 앱 및 서비스 에서 shorts-maker 의 접근 권한을 언제든 없앨 수 있어요.

7. 바뀔 때와 문의

이 방침이 바뀌면 이 페이지의 최종 수정일을 고쳐요. 문의: github.com/laterior2024

Privacy Policy (English)

Scope. shorts-maker is a personal short-video editing tool that runs on the operator's own computer. This policy explains how it uses information received through Google sign-in (YouTube).

Scopes and use. youtube.upload is used only to upload finished videos and set thumbnails on the operator's own connected channels. youtube.force-ssl is used to post a pinned comment on those uploads, read the connected channel's name and profile picture, and read public comments (text and like counts) of source videos for editing reference. No other purposes (advertising, sale, training other services).

Storage. OAuth tokens, connected channel id/name/handle/picture, and public comment text with like/reply counts are stored only in the program folder on the operator's computer. Comment authors' names or accounts are not stored. Nothing is sent to any server run by the operator.

Sharing. Google user data is never sold or transferred to others. Public comment text (without author names) may be sent to an AI writing service (Anthropic Claude API) solely to summarize audience reactions for editing.

Google API Services User Data Policy. shorts-maker's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Disconnect a channel in the program's settings, or revoke shorts-maker at myaccount.google.com/permissions.
